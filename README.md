# BroadWorks Enhancer PJAX Preview

This branch combines the original BroadWorks Enhancer controls with the PJAX transport from Modern-Commpilot. The CommPilot 2.0 theme redesigns the shared header, navigation, menus, lists, forms, tabs, and dialogs while keeping CommPilot's page structure and controls in their familiar locations. It bundles Inter and Geist fonts plus local navigation icons, so the interface does not depend on a font service. The former `skin.js` and `skin.css` are retained in Git history but are not loaded by this extension.

## Included behavior

- The top bar, breadcrumb, and left navigation stay in place while only the right-hand workspace scrolls. Folder home pages show their Profile, Resources, Services, calls, and other options together on one scrolling board, using CommPilot's existing links and sidebar order. Each folder has a slim title rule whose accent tracks the active section; the large outer folder panels have been removed. A click anywhere in an option row follows its native CommPilot link. Peek shows selected settings within the board as they come into view, only for options whose pages hold a few settings, so each preview stays small. At reseller level, notification email values support Copy and inline Edit. At group level, Peek shows Emergency Call Notification (alert status and an editable Send to address), Extension Length, Device Activation Policy, and Call Center External Reporting. At user level, Peek shows and edits Anonymous Rejection, Do Not Disturb (with ring splash), Call Waiting (with hide caller ID), Remote Office (with its number), Call Forwarding Always, Busy, and Not Reachable (with the forward-to number, plus ring splash for Always), and Voice Portal Calling; On/Off settings edit through an On/Off choice. Every save uses the page's own Apply and is confirmed from the server's response and from a fresh re-read; pages with password or file fields are never edited from Peek. Peek reads and saves never overlap an option you open: a read waits for the page change and is dropped once its board is gone, so CommPilot's single-use form token is never spent twice. Lists, searches, forms, and deeper settings keep their native controls. PJAX restores the board scroll position on Back. In every palette, the green/red On/Off service labels keep at least 4.5:1 contrast, the Copy User ID and Copy Extension buttons use the theme's type, and sorted list columns show a chevron in the header's color instead of CommPilot's boxed GIF arrow. Forms follow the layouts picked from the 2.0 mockups, while CommPilot's own controls stay in the form and are what OK, Apply and PJAX submit: list search criteria sit on one toolbar line (Search beside the value; **+ Add criteria** presses CommPilot's own +); small settings forms such as Call Forwarding, Do Not Disturb and Add Schedule become rows with On/Off segments and switches (pages with password or file fields, nested tables, or more than ten rows keep CommPilot's layout); Available / Assigned lists become paired cards with counts, filters, click / shift-click / double-click selection and move buttons that press CommPilot's own; and the schedule event editor shows a plain-English summary with date and time pickers, an All-day switch, Repeats segments and weekday chips (Monthly / Yearly patterns and the recurrence range stay CommPilot's own rows below it). Every page shares one baseline: its content sits on a single card with nothing boxed inside it; OK, Apply and Cancel sit beside the page title and stay in reach while the page scrolls (CommPilot's duplicate bottom bar is hidden; bars that hold text or fields stay as a plain row); result lists use compact rows with plain Edit links and a one-line pager; fieldsets become labelled sections; and spacing follows the window width and tightens on short screens such as a 1080p laptop at 150% scaling, so pages need about as much scrolling as unskinned CommPilot. Result lists fill the window: PJAX fetches a list's other CommPilot pages (up to 50) in the background, threading the single-use form token and stopping for any navigation, and the list shows as many rows as fit with a pager that refits when the window is resized; if a page cannot be fetched, CommPilot's own 20-row pager stays. A click anywhere on a result row (or Enter on it) opens it, the Edit column is hidden where it only repeats the row's link, and the row under the pointer gets a quiet tint instead of CommPilot's link highlight. While CommPilot answers a search or a click, the page's card eases back and a thin bar runs along its top; the results then appear once, already paged to the window with the Edit column gone, and the rest of the list loads in behind the pager (which says so) without moving a row or a column. Once a list is complete, clicking a column header sorts it in place (click again to reverse) instead of searching again; the order is kept when you come back to the list in the same tab. The pager shows the count on the left and the page selector in the middle, with first, previous, next and last buttons. The breadcrumb is the v0.2 alpha's pill trail in the palette's colours: a route icon leads, each level is an uppercase pill with an arrow between, and the current place (the page pill, else the user or other entity, else the last level) is the accent pill; a user id keeps its own case, and the Users list link that only repeats the user's id is hidden. The levels are CommPilot's own links, so they navigate as before. Saving a page (OK, Apply or Delete) never adds a Back step that could re-send the save: Back returns to where you were before the page. A page reopened with the browser Reload button keeps the 2.0 layout. After a level's board has loaded, that level's other pages show the current page as a breadcrumb pill whose menu lists every folder's pages, grouped Basic / Advanced; choosing one opens it in place with the option's own target. The browser Reload button reopens the same service-provider, group, or user board, including one reached through CommPilot's own breadcrumb links, and Back from a page opened there returns to that board. At service-provider, group, and user levels, the board completes its menu reads and restores the selected entity before linked pages open; a failed read blocks those links and offers Retry menu.
- Peek reserves the full dock height for known multi-value pages as each board section is first revealed, then reads values after all folder pages finish loading. Values appear together in one compact dock with a crossfade, without a height animation or staggered rows. Failed or empty previews collapse away; reduced-motion settings skip the animation.

## Install this preview

Extract BroadWorks-Enhancer-PJAX-Preview-0.3.76.zip from the [0.3.76 release](https://github.com/KeelrLeek/Modern-Commpilot/releases/tag/v0.3.76-pjax-preview). The project release folder also has a matching versioned ZIP and reloadable `release/unpacked/` folder. The generic `release/BroadWorks-Enhancer-PJAX-Preview.zip` is refreshed when a browser is not holding it open. Chrome or Edge: open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select the extracted folder. Firefox or Zen: open `about:debugging#/runtime/this-firefox`, choose **Load Temporary Add-on**, and select `manifest.json` from the extracted folder or the project's `release/unpacked/`. Reload the temporary add-on and refresh CommPilot after replacing its files. Disable the stable BroadWorks Enhancer while testing this preview to avoid duplicate controls. No helper or separate installer is needed. Use **Settings** beside Help and Home (palettes, the site's font, Menu previews, and About with what's new) or the extension toolbar popup to switch palettes.

On the login page, open **Saved sign-ins**, choose **Add login**, enter your User ID and Password, and select **Sign in automatically** or **Ask for a four-digit PIN**. Later, choose an account if you have several saved. A PIN account asks for its PIN before using Cisco's original Login handler. Use **Remove** to delete a saved account. Saving is per BroadWorks host. Recent manual logout and login errors suppress an immediate automatic retry to avoid sign-in loops. Accounts saved by version 0.3.3 can be moved into this version by entering the previous vault password once.

Automatic sign-in requires the encryption key to persist in the browser profile. This protects passwords from casual inspection of extension storage, but a person or program with access to the browser profile and extension privileges may still use the key. The four-digit PIN is a convenience gate, not the equivalent of Windows Credential Manager or a master-password vault.

Logins saved by the earlier Windows-helper preview are not imported into this vault. They remain in Windows Credential Manager until you remove them separately; re-add them here if needed.

The extension ID in Chrome and Edge is pinned to `gahgpfcnalnjfnlchhlhknidgnpllojg`. Firefox uses `broadworks-enhancer-pjax@example.com`.

The extension is scoped to the seven known BroadWorks hosts. The PJAX code only runs under `/commpilot/`.

## Tests

Run `npm ci` and `npm test`. The tests load the extension in Chromium, exercise the prior enhancer cases, navigate through representative PJAX page families including deeper route patterns and an iframe drill-in, and test a reload recovery path. The shared theme was checked visually on live sandbox pages and at 1024px on the densest forms. The saved-login test checks ciphertext storage, the non-extractable browser key, correct and incorrect PINs, account selection, automatic sign-in, and removal. Firefox lint reports no errors; it still reports warnings for `innerHTML` assignments in the inherited PJAX code.

`npm run test:live` runs a headless smoke check against the sandbox only (set `BW_LIVE_PROFILE` to an Edge profile that holds a saved sandbox sign-in). It signs in, loads the reseller Peek docks, opens and leaves an option, drills to a user, saves one Peek setting and restores it with a fresh read, reloads the User and Service Provider boards, and climbs the native breadcrumb. It writes `dev-preview/live-smoke/report.html` and exits non-zero on a failure.
