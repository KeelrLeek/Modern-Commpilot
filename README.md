# BroadWorks Enhancer PJAX Preview

This branch combines the original BroadWorks Enhancer controls with the PJAX transport from Modern-Commpilot. The CommPilot 2.0 theme redesigns the shared header, navigation, menus, lists, forms, tabs, and dialogs while keeping CommPilot's page structure and controls in their familiar locations. It bundles Inter and Geist fonts plus local navigation icons, so the interface does not depend on a font service. The former `skin.js` and `skin.css` are retained in Git history but are not loaded by this extension.

## Included behavior

- The top bar, breadcrumb, and left navigation stay in place while only the right-hand workspace scrolls. Folder home pages show their Profile, Resources, Services, calls, and other options together on one scrolling board, using CommPilot's existing links and sidebar order. Each folder has a slim title rule whose accent tracks the active section; the large outer folder panels have been removed. Lists, searches, forms, and deeper settings keep their native controls. PJAX restores the board scroll position on Back. At service-provider, group, and user levels, the board completes its menu reads and restores the selected entity before linked pages open; a failed read blocks those links and offers Retry menu.
- The original dropdown search, green/red On/Off labels, and breadcrumb Copy User ID / Copy Extension controls. Large native dropdowns now render only the visible options, keeping searches responsive even with over 18,000 matches.
- Group Resources → Numbers includes **Bulk assign departments**. Download the blank Excel template and enter a phone number and department on each row. An optional **Range End** assigns every number from Phone Number through Range End, inclusively; multiple range rows are supported. Use `None` to clear a department. The tool expands up to 2,000 numbers, flags missing or duplicate numbers and invalid departments, and blocks Apply until the preview has no errors. Large-group lookups accept international numbers entered as digits even when CommPilot stores a hyphen after the country code. It skips numbers already in the requested department. Before each save it reads the number's current department from the Numbers list; the Edit dropdown is only an assignment control. Apply shows the current number and progress, saves sequentially, then reads the group list again (or performs exact lookups) to show **Before**, **Requested**, and verified **After** values. You can stop after the current number; saved rows are not rolled back. Re-uploading the same workbook previews completed assignments as already correct. If CommPilot cannot return readback data, the tool marks saved rows unverified rather than claiming they succeeded.
- Group Resources → Identity/Device Profiles includes **Clean up unused profiles**. Download its blank Excel template and enter one extension per row. The tool searches profile names with CommPilot's **Contains** filter, shows every matching name in a paged preview, and keeps profiles with assigned lines or Users rows. After a confirmation, it checks each profile again, requests Delete for eligible profiles one at a time, and searches the list afterward to show **Before**, **After**, and whether CommPilot deleted or refused it. Stop after the current profile is available during a run. Missing extensions and profiles in use are shown without deletion. A disposable sandbox profile was created, deleted, and confirmed absent with this workflow; production deletes remain for the user to test.
- Group Resources → Activate Numbers includes **Activate all deactivated numbers**. Scan the group without a workbook: the tool sorts CommPilot's Activated column so deactivated rows come first, reads their checkmarks, and stops at the first activated row. It counts numbers in displayed ranges and shows a Before/After preview. After confirmation it rechecks each deactivated row, opens its edit form, sends CommPilot's Add action directly through PJAX, saves, and reads the row back before marking it verified. It stops on the first error; Stop finishes the current row. Sandbox checks verified the sort order and a temporary deactivate → bulk activate cycle, with the test number restored to its original activated state. Browser tests cover early stopping with 206 advertised pages, ranges, saving, readback, and a page where the native Add button has no click handler.
- Group Utilities → Group Directory includes **Export directory**. Choose users only or every directory entry, including service lines. The extension reads CommPilot's detailed report by department and downloads a ZIP with a full workbook and a customer phone directory workbook. The sandbox export was verified in both modes against a group with three departments.
- Reseller pages include **Help tips** below the native sidebar. Turn it on to see the original branch's explanations for 31 reseller menu items and six sidebar folders when hovering. Escape closes the tips. CommPilot's existing Help link keeps working. The active level is read from CommPilot's breadcrumb, so Help tips also appear on the Reseller home page at the shared `/Common/folder_contents.jsp` URL and stay off Group and User pages that the original descriptions do not cover.
- PJAX navigation for reseller, service-provider, group, user, and Operator pages, including deeper settings trees; folder menus; list find/sort/page requests; tab switches; and entity drill-in.
- Form-token rotation, bounded redirect-stub following, iframe transport for navigation-only entity pages, in-place server-error handling, back/forward replay that preserves Forward after an iframe drill-in, and same-origin reload recovery. A rejected navigation with no recoverable session token opens sign-in once instead of repeatedly posting it.

Its Completed tab stays inside the Scheduled Reports folder, and Calling Plan tabs with query flags now switch in-shell. Group Activate Numbers returns to its list URL after saving. ## Install this preview

Extract [BroadWorks-Enhancer-PJAX-Preview-0.3.50.zip](release/BroadWorks-Enhancer-PJAX-Preview-0.3.50.zip). The project release folder also has a matching versioned ZIP and reloadable `release/unpacked/` folder. The generic `release/BroadWorks-Enhancer-PJAX-Preview.zip` is refreshed when a browser is not holding it open. Chrome or Edge: open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select the extracted folder. Firefox or Zen: open `about:debugging#/runtime/this-firefox`, choose **Load Temporary Add-on**, and select `manifest.json` from the extracted folder or the project's `release/unpacked/`. Reload the temporary add-on and refresh CommPilot after replacing its files. Disable the stable BroadWorks Enhancer while testing this preview to avoid duplicate controls. No helper or separate installer is needed. Use **Appearance** beside Help and Home or the extension toolbar popup to switch palettes.

On the login page, open **Saved sign-ins**, choose **Add login**, enter your User ID and Password, and select **Sign in automatically** or **Ask for a four-digit PIN**. Later, choose an account if you have several saved. A PIN account asks for its PIN before using Cisco's original Login handler. Use **Remove** to delete a saved account. Saving is per BroadWorks host. Recent manual logout and login errors suppress an immediate automatic retry to avoid sign-in loops. Accounts saved by version 0.3.3 can be moved into this version by entering the previous vault password once.

Automatic sign-in requires the encryption key to persist in the browser profile. This protects passwords from casual inspection of extension storage, but a person or program with access to the browser profile and extension privileges may still use the key. The four-digit PIN is a convenience gate, not the equivalent of Windows Credential Manager or a master-password vault.

Logins saved by the earlier Windows-helper preview are not imported into this vault. They remain in Windows Credential Manager until you remove them separately; re-add them here if needed.

The extension ID in Chrome and Edge is pinned to `gahgpfcnalnjfnlchhlhknidgnpllojg`. Firefox uses `broadworks-enhancer-pjax@example.com`.

The extension is scoped to the seven known BroadWorks hosts. The PJAX code only runs under `/commpilot/`.

The shared theme was checked visually on live sandbox pages and at 1024px on the densest forms.
