# BroadWorks Enhancer PJAX Preview

Stable **0.3.84** fixes recovery after an expired session, stops unintended and repeated saves, and makes pick lists, bulk tools, lists, sign-in and navigation more reliable.

## 0.3.84 patch notes

- **Session recovery.** When a session has expired on a user, group or service-provider page, reloading goes to sign-in and reopens that page afterwards instead of stopping on "Page recovery paused" (a 0.3.83 regression). The pause now appears only for real server failures and offers **Go to login** beside Retry. Reload recovery no longer shows CommPilot's raw stylesheet text while it works.
- **Saves.** A second OK/Apply, or a double-clicked "also saves current screen data" link, is ignored while the first save is pending. A click, F5 or Back that gives up behind a slow save or upload no longer discards that save's result. Enter in a pick-list Filter box no longer presses OK. Sign out waits for a pending save.
- **Navigation.** A failed Back/Forward puts the address back on the page still on screen, so its Apply posts to that page. F5 refreshes the page on screen. After a schedule event's OK, the schedule page's Add and Apply work again instead of returning 404. A failed or overtaken return after sign-in no longer reopens an old page after your next click, and a deliberate sign-out forgets the tab's return page.
- **Pick lists.** The Assign Domains shortcut no longer takes over other pick lists: Remove works again on Privacy, Assign Call Centers and similar pages, and Assign Services' service-pack buttons post the right list. Filtered-out options are never moved, and large lists respond faster.
- **Bulk tools.** International number ranges keep their country code for caller ID; ambiguous formats are reported instead of guessed. Continue to passwords explains row problems. The number picker has **Refresh numbers**, and Enter picks only a typed, matching number. Review recovers after a failed check, and Close asks before discarding users already started. Number bulk and profile cleanup reopen their list instead of reusing a spent session token, number bulk ignores a search filter left on the page, and profile cleanup can be stopped.
- **Lists and exports.** A superseded search no longer flashes the old search's partial results. Export stops if the page changes, Load all leaves one results heading, the sort chevron survives a theme change, and Group Directory export reads each group's own departments.
- **Sign-in, Settings and updates.** Enter cannot send duplicate sign-ins, Esc frees a stopped sign-in, and re-saving a saved User ID updates it. A known update stays downloadable after a failed check, keyboard focus stays in Settings, and the toolbar icon follows a theme picked in the popup.
- **Performance and layout.** The loading line no longer restyles the whole page while CommPilot works, pages with many dropdowns no longer freeze, and the extension stays out of its own hidden transport frames. The breadcrumb arrow is repaired after in-page navigation, menus close when you navigate, and keyboard focus is kept.
- **Validation.** All 150 test files passed 995/995 in headless Edge with synthetic CommPilot fixtures, and the tests that load the packaged extension passed 645/645. Live PBX behavior and Firefox/Zen at runtime were not exercised.

## Install this preview

Extract `BroadWorks-Enhancer-PJAX-Preview-0.3.84.zip` from the project release folder, or use its matching reloadable `release/unpacked/` folder. The generic `release/BroadWorks-Enhancer-PJAX-Preview.zip` is refreshed when a browser is not holding it open. Chrome or Edge: open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select the extracted folder. Firefox or Zen: open `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on**, and select `manifest.json` from the extracted folder or the project's `release/unpacked/`. Reload the temporary add-on and refresh CommPilot after replacing its files. Disable the stable BroadWorks Enhancer while testing this preview to avoid duplicate controls. No helper or separate installer is needed. Use **Settings** beside Help and Home (twelve themes, each light or dark, the site's font, Menu previews, and About with what's new) or the extension toolbar popup to switch themes.

On the login page, open **Saved sign-ins**, choose **Add login**, enter your User ID and Password, and select **Sign in automatically** or **Ask for a four-digit PIN**. Later, choose an account if you have several saved. A PIN account asks for its PIN before using Cisco's original Login handler. Use **Remove** to delete a saved account. Saving is per BroadWorks host. Recent manual logout and login errors suppress an immediate automatic retry to avoid sign-in loops. Accounts saved by version 0.3.3 can be moved into this version by entering the previous vault password once.

Automatic sign-in requires the encryption key to persist in the browser profile. This protects passwords from casual inspection of extension storage, but a person or program with access to the browser profile and extension privileges may still use the key. The four-digit PIN is a convenience gate, not the equivalent of Windows Credential Manager or a master-password vault.

Logins saved by the earlier Windows-helper preview are not imported into this vault. They remain in Windows Credential Manager until you remove them separately; re-add them here if needed.

The extension ID in Chrome and Edge is pinned to `gahgpfcnalnjfnlchhlhknidgnpllojg`. Firefox uses `broadworks-enhancer-pjax@example.com`.

The extension is scoped to the seven known BroadWorks hosts. The PJAX code only runs under `/commpilot/`.

## Update channels in the development checkout

**Settings → Updates** is available inside CommPilot, with Stable/Nightly selection, automatic daily/startup checks, a manual check button, release notes, and download/install instructions. It uses the existing Settings typography, theme controls, and selected site font. Stable is the default. Checks use public GitHub metadata from the extension background worker, send no CommPilot data or credentials, and do not submit forms, install code, or reload active pages. Automatic checks can be disabled.

Stable reads this repository's latest published non-prerelease. Release **0.3.84** is the current Stable release; the `stable` branch and `v0.3.84-pjax-preview` tag identify its source commit. Previous releases remain available. Nightly reads only the dedicated `nightly` prerelease; old beta releases do not count as nightlies. Until a nightly is published, the checker says so. A nightly must carry one uploaded ZIP named `BroadWorks-Enhancer-PJAX-Preview-A.B.C.D-nightly.zip`, with a numeric manifest version matching its filename and greater than the build it replaces. Stable ZIP names and version tags remain unchanged. Switching channels does not install or downgrade anything.

The checker ships since 0.3.83; installs of 0.3.83 or later offer 0.3.84 under Settings → Updates. Users of the original 0.3.82 package must download a newer release from GitHub to receive it. Published ZIPs of earlier releases are preserved. Updating an unpacked installation still requires extracting the downloaded ZIP into its folder, reloading the extension, and refreshing CommPilot after finishing unsaved work.

## Tests

The [October 21–22 hardening report](docs/hardening-2026-10-22.md) describes the navigation/session, native-form, bulk, export, storage and performance changes, with revision-specific validation and remaining live-verification limits. The report records the pre-release 0.3.82 audit checkpoint; the validated changes now ship in 0.3.83, without replacing the old 0.3.82 ZIP.

Run `npm ci` and `npm test`. The tests load the extension in Chromium, exercise the prior enhancer cases, navigate through representative PJAX page families including deeper route patterns and an iframe drill-in, and test a reload recovery path. The shared theme was checked visually on live sandbox pages and at 1024px on the densest forms. The saved-login test checks ciphertext storage, the non-extractable browser key, correct and incorrect PINs, account selection, automatic sign-in, and removal. Firefox lint reports no errors; it still reports warnings for `innerHTML` assignments in the inherited PJAX code.

`npm run test:live` runs a headless smoke check against the sandbox only (set `BW_LIVE_PROFILE` to an Edge profile that holds a saved sandbox sign-in). It signs in, loads the reseller Peek docks, opens and leaves an option, drills to a user, saves one Peek setting and restores it with a fresh read, reloads the User and Service Provider boards, and climbs the native breadcrumb. It writes `dev-preview/live-smoke/report.html` and exits non-zero on a failure.
